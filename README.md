# Rechor project
## Goal:
- The goal of this school project was to familiarize myself with the use of java through a real-world use case

## Tools:
- Many layers were necessary for this project, the modelization of transport entities using classes and records as well as designing an algorithm to be able to search for transports.
- JavaFX was used to make the interface, by providing drop-down menus and editable boxes for the user.
